GLASSGUARD — PREMIUM / SMOOTH SCROLL UPDATE

Use this complete folder as the website. Keep index.html, finder.html,
app.js, style.css, premium.css, fonts, and all nine frame folders together.
Upload the contents to your static web hosting root, then open index.html.
No package install or build step is required. A local HTTP preview is
recommended; browsers may restrict iframe sizing when using file://.

Updated:
- Self-hosted Manrope variable font, including its open-source license.
- Refined floating glass navbar, active sections and keyboard-accessible
  mobile navigation with Escape/outside-click dismissal.
- Eased desktop mouse-wheel scrolling, with native touch scrolling.
- Time-based frame easing and adjacent-frame blending.
- One shared animation scheduler; decoded frames are retained only near
  the current story, with four concurrent frame requests maximum.
- Adaptive canvas resolution, nearby-frame loading and offscreen cleanup.
- Hero-ready entry loader and non-blocking image-error fallback.
- Mobile text alignment and dynamic finder iframe sizing.
- Reduced-motion preference support and visible keyboard focus.

The original product content, section order, product database, WhatsApp
number, frame images, colors, and overall section design are retained.

Browser checks: desktop (1440px), tablet (768px), and mobile (390px)
render all nine frame sequences without JavaScript or resource errors.
Additional checks cover 320px / 390px / 1024px layouts, wheel settling,
mobile menu, finder selection/quantity, and reduced-motion behavior.

Actual smoothness also depends on device speed and hosting/network speed.
Touch scrolling remains native to the device. Frame blending uses the
supplied images; it does not generate new in-between image content.
